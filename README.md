### Базовый запуск

```bash
npm ci
npm test
```

### HTML Report

Запуск HTML-репорта после выполнения тестов:

```bash
npm run report
```

### Параллельный запуск

Для параллельного запуска задано 3 worker:

```bash
npm run test:parallel
```

> `.env` добавлен, чтобы не создавать вручную, так как это тестовый проект.
